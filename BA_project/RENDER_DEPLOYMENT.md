## 🚀 Quick Deploy (3 Steps)

### Step 1: Push to GitHub

```bash
# Navigate to project
cd /Users/nguyenthanhlam/BA_project

# Initialize git (if not already)
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit: Movie recommender with A/B testing"

# Create GitHub repo and push
# Go to: https://github.com/new
# Name: ba-movie-recommender
# Then:

git remote add origin https://github.com/YOUR_USERNAME/ba-movie-recommender.git
git branch -M main
git push -u origin main
```

### Step 2: Create Render Service

1. **Go to:** https://dashboard.render.com
2. Click **"New +"** → **"Web Service"**
3. Connect your GitHub repository
4. Select `ba-movie-recommender`

### Step 3: Configure Service

Render will auto-detect `render.yaml` and use these settings:

```yaml
Name: ba-movie-recommender
Environment: Python
Region: Oregon (or closest to you)
Branch: main
Root Directory: BA_project
Build Command: pip install -r requirements.txt
Start Command: gunicorn --bind 0.0.0.0:$PORT --workers 2 --timeout 60 app:app
```

Click **"Create Web Service"** → Wait 3-5 minutes for build.

## 🐛 Troubleshooting

### Build Failed

**Error:** `pip install failed`

**Fix:**
```bash
# Check requirements.txt is in BA_project folder
ls BA_project/requirements.txt

# Test locally first
cd BA_project
pip install -r requirements.txt
python app.py
```

### App Crashes on Start

**Error:** `Application failed to start`

**Check Render logs for:**
```
ModuleNotFoundError: No module named 'X'
```

**Fix:** Add missing package to `requirements.txt`

### Recommendations Not Showing

**Symptoms:** Empty recommendations array

**Debug:**
1. Check Render logs:
   ```
   [Recommender] Using local sample data
   ```
2. Test locally first:
   ```bash
   cd BA_project
   python app.py
   # Visit http://localhost:5000
   ```
3. Check if movies loaded:
   ```bash
   curl https://YOUR-APP.onrender.com/api/movies
   ```

### App Sleeps After 15 Minutes

**This is normal for Render Free Tier:**
- App sleeps after 15 min of inactivity
- First request after sleep takes ~30s to wake up
- After wake, works normally

**Solutions:**
- Upgrade to paid plan ($7/month for always-on)
- Use cron job to keep alive:
  ```bash
  # In cron-job.org or similar
  */14 * * * * curl https://YOUR-APP.onrender.com/health
  ```

### MongoDB Connection Failed

**Error:** `ServerSelectionTimeoutError`

**Fix:**
1. Check MongoDB Atlas IP whitelist:
   - Go to Atlas → Network Access
   - Add: `0.0.0.0/0` (allow all)
2. Verify `MONGODB_URI` in Render environment variables
3. Test connection:
   ```bash
   # In Render Shell
   python scripts/test_mongodb.py
   ```

## 🎯 Optimization Tips

### 1. Reduce Cold Start Time

Add this to `app.py`:
```python
@app.before_first_request
def warmup():
    """Warm up the app on first request"""
    # Preload recommendations
    from utils.recommender import dataset
    _ = dataset.get_all_movies()
```

### 2. Enable Caching (Redis)

For faster recommendations:

```python
# Add to requirements.txt
redis==5.0.1

# In app.py
from flask_caching import Cache
cache = Cache(app, config={'CACHE_TYPE': 'redis'})

@cache.memoize(timeout=300)
def get_cached_recommendations(user_id, variant):
    return get_recommendations(user_id, variant)
```

**Render Redis:** $3/month add-on

### 3. Use MongoDB for Better UX

```bash
# In Render environment
USE_MONGODB_MOVIES=true
MONGODB_URI=mongodb+srv://...
```

**Benefits:**
- 21,000+ real movies
- Real TMDB posters
- Better personalization
- More genres, ratings
